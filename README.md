# 🎭 Automation Exercise - Login Automation with Selenium WebDriver

This repository contains an automated test script for validating the user login functionality on [Automation Exercise](https://www.automationexercise.com/) using **Selenium WebDriver** and **JavaScript (Node.js)**.

---

## 📌 Test Scenario Covered
1. Launch browser and navigate to `https://www.automationexercise.com/`.
2. Maximize the window.
3. Click on **Signup / Login** button.
4. Enter registered **Email** and **Password**.
5. Click **Login** button.
6. Verify successful login by asserting the presence of `Logged in as <username>` text.

---

## 🛠️ Tech Stack & Prerequisites
* **Language:** JavaScript (Node.js)
* **Framework:** `selenium-webdriver`
* **Browser:** Chrome / Brave
